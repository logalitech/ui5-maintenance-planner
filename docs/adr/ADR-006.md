# ADR-006. Anotaciones de interfaz locales en la aplicación

Estado: aceptada.

## Contexto

El servicio no publica anotaciones de disposición de interfaz: no tiene `UI.LineItem`, `UI.SelectionFields`, `UI.HeaderInfo`, `UI.Facets` ni `UI.FieldGroup`. Sí publica las anotaciones de comportamiento (borrador, control de acciones, ayudas de búsqueda, textos, efectos laterales).

En un proyecto RAP, las anotaciones de interfaz suelen ir en extensiones de metadatos (`DDLX`) del backend. En este proyecto el equipo de frontend no puede modificar el servicio, que además consumen otras aplicaciones y otros usuarios, y cada activación en el backend afecta a todos.

## Decisión

Todas las anotaciones de interfaz se escriben en `webapp/annotations/annotation.xml`. El servicio no se modifica.

## Consecuencias

- La aplicación es independiente del calendario del equipo de backend.
- Si en el futuro el backend publica anotaciones de interfaz, las locales prevalecen sobre las del servicio cuando coinciden destino, término y calificador, y lo sustituyen entero.
- Los textos de las anotaciones se traducen con el modelo `@i18n` (`{@i18n>clave}`), igual que el resto de la aplicación.
