# ADR-007. Flexible Programming Model solo donde no llega la anotación

Estado: aceptada.

## Contexto

Algunas necesidades no tienen una anotación que las exprese: por ejemplo, mostrar en miniatura las imágenes adjuntas o abrir una página de indicadores desde la bandeja.

El Flexible Programming Model permite añadir secciones, columnas, acciones y páginas propias en puntos previstos por las plantillas, sin reescribirlas.

## Decisión

1. Primero se busca la anotación o el ajuste del `manifest.json` que resuelve la necesidad.
2. Solo si no existe, se usa un punto de extensión del Flexible Programming Model.
3. El código propio vive en `webapp/ext/`, en TypeScript, y usa el contexto de enlace que proporciona Fiori elements.

## Consecuencias

- La mayor parte de la aplicación sigue sin código y se beneficia de las mejoras de cada versión de Fiori elements.
- Cada extensión está declarada en el `manifest.json`, donde se ve de un vistazo qué parte no es estándar.
