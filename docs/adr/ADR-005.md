# ADR-005. Fiori elements para la bandeja del planificador

Estado: aceptada.

## Contexto

El planificador revisa muchos avisos a la vez, los filtra, los ordena y decide si los asigna o los rechaza. Es el patrón de lista con filtros y detalle que SAP Fiori cubre con plantillas estándar.

La aplicación freestyle del proyecto ya resuelve el trabajo del operario y del técnico, con necesidades que no encajan en una plantilla (alta con fotos, vista previa, captura con cámara). Modificarla para el planificador mezclaría dos formas de trabajo en una sola aplicación.

El servicio ya publica el borrador, el control dinámico de las acciones, las ayudas de búsqueda y los efectos laterales: lo que una aplicación de Fiori elements necesita para funcionar sin código.

## Decisión

El planificador tiene una aplicación propia, generada con SAP Fiori tools con la plantilla List Report Page para OData V4 sobre el mismo servicio. La aplicación freestyle no se modifica.

## Consecuencias

- La interfaz sigue las directrices de diseño de SAP Fiori sin trabajo adicional: variantes, personalización de tablas, exportación a hoja de cálculo, mensajes y borrador.
- El comportamiento de la lista y del detalle se decide con anotaciones y con la configuración del `manifest.json`, no con código.
- Lo que la plantilla no cubre se añade en los puntos de extensión del Flexible Programming Model (ADR-007).
- Las dos aplicaciones comparten servicio y datos: un cambio en una se ve en la otra.
