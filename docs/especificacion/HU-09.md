# HU-09. Aplicación del planificador generada

Sesión de trabajo conjunta.

## Historia

Como planificador, quiero una aplicación de bandeja con lista y detalle de avisos, para revisarlos sin esperar a un desarrollo a medida.

## Criterios de aceptación

1. El proyecto se genera con el generador de aplicaciones de SAP Fiori tools con los datos de las notas técnicas.
2. `npm start` abre la vista previa del launchpad; "Ir" carga avisos del servicio real.
3. Al pulsar una fila se abre el detalle del aviso.
4. "Crear" abre un borrador nuevo; "Editar", "Guardar" y "Descartar borrador" funcionan con el borrador del servicio.
5. Las ayudas de búsqueda de planta y equipo funcionan en la edición.
6. El título y la descripción de la aplicación están en inglés y en español.
7. No hay código en controladores.

## Datos

Ninguno.

## Notas técnicas

| Pregunta del generador | Respuesta |

| Plantilla | List Report Page |
| Fuente de datos | Connect to an OData Service |

| Entidad principal | `Requests` |
| Entidad de navegación | `_Task` |
| Nombre del módulo | `maintenance-planner` |
| Título | `Planificación de avisos` |
| Espacio de nombres | `sapui5` |
| TypeScript | Sí |
| Versión mínima de SAPUI5 | 1.148 |

- El id resultante es `sapui5.maintenanceplanner`: el generador une el espacio de nombres y el nombre del módulo sin el guion.
- Las credenciales van en `.env` (`FIORI_TOOLS_USER`, `FIORI_TOOLS_PASSWORD`), excluido de git.
- Sin anotaciones de interfaz, la tabla de la lista aparece vacía con el texto "Agregar columnas para ver el contenido". Es el punto de partida de HU-10.
